# CLAUDE.md

Правила для AI-ассистента в этом репозитории.

## Перед выпуском: PR и алерты GitHub

Получив команду на патч или релиз — ПЕРВЫМ шагом, до bump версии, тега и деплоя:

1. Проверить GitHub репозитория: открытые PR (`gh pr list --state open`) и алерты —
   Dependabot (`gh api "repos/{owner}/{repo}/dependabot/alerts?state=open"`), а если
   включены, code scanning и secret scanning.
2. Показать владельцу список (PR; алерты числом по severity и runtime/dev) и спросить,
   что закрыть до выпуска. Отобранное устранить ДО выпуска: обновить зависимость или
   lock-файл, прогнать тесты, смержить или закрыть PR. Алерт по dev-зависимости или
   по lock-файлу, который на прод не попадает, — назвать как есть, а не прятать.
3. Пусто — одной строкой в отчёте, и дальше по обычной процедуре выпуска.

# Локальный граф документации для агентов

Агент может работать с документацией, доступной **вашему** аккаунту, и построить собственный локальный граф. Здесь опубликованы инструменты, примеры с вымышленным содержимым и [карта навигации](documentation-graph.json): 200 записей, 762 узла и 1113 связей. Карта включает руководства платформы, навигацию по операциям, переходу с 7.7 и базе знаний PO.BY. Названия и ссылки помогают найти источник; наличие ссылки не подтверждает доступ, актуальность или применимость к вашей конфигурации.

Тексты статей, пересказы, снимки браузера, результаты входа в чужой аккаунт и учетные данные в поставку не входят. Права на материалы остаются у соответствующих правообладателей. Лицензия проекта относится к коду инструментов; она не предоставляет права на содержимое порталов. Перед локальным сохранением учитывайте условия доступа и разрешенное использование своего аккаунта.

## Пример без аккаунта и без текстов правообладателя

Нужен Python 3.10+; внешних Python-зависимостей у этих скриптов нет. Из корня репозитория:

```bash
python docs/toolkit/examples/make_demo.py --output /tmp/onec-docs-demo
python -m unittest discover -s docs/toolkit/tests
```

Первый вызов создает 42 **вымышленные** входные страницы, Markdown/JSON-пары, каталог и граф. URL служат примерами идентификаторов; программа не загружает страницы. Выходной каталог должен быть новым. Повторный импорт того же корпуса проверяется тестом отдельно.

```bash
python docs/toolkit/scripts/collect.py developer /tmp/onec-docs-demo/raw \
  --output /tmp/onec-docs-demo/corpus --observed 2026-01-01
python docs/toolkit/scripts/export_navigation.py /tmp/onec-docs-demo/corpus \
  --output /tmp/onec-docs-demo/navigation.json
```

## Chrome, аккаунт и портал

1. Пользователь открывает официальный портал и выполняет вход в своем обычном профиле Chrome. Пароль, MFA и согласие с условиями остаются в интерфейсе портала. Подключенный к агенту браузерный плагин должен иметь доступ к этой вкладке; конкретные команды зависят от плагина.
2. Агент читает видимую страницу и определяет, открыт ли материал, форма входа или сообщение об ограничении подписки. Вход не равен праву на любую статью. При ограничении сохраняют только статус `restricted` в локальном журнале и останавливают получение этого материала.
3. Агент выбирает **фрейм самой статьи** и проверяет область с заголовком и содержимым. [capture-article.js](examples/capture-article.js) выполняется в этом фрейме через browser evaluate. Передайте проверенный `articleSelector` и `confirmArticleOnly: true`; для указателей операций также `collection: "hoosn-index"`. Не выполняйте захват всей оболочки портала. Если плагин не умеет выбирать фрейм, пользователь может открыть канонический URL статьи в отдельной вкладке; обход ограничений браузера не требуется.
4. Сохраните полученный JSON локально как `<source_id>.json`. Скрипт читает DOM выбранной статьи, исключает формы, скрипты, элементы навигации и URL с параметрами. Он не обращается к cookies, localStorage, заголовкам запросов или профилю. Проверьте область и результат перед сохранением: фильтр не может распознать произвольные персональные данные в тексте.
5. Передайте **полный** результат. Если браузерный инструмент обрезал длинный ответ, используйте поддерживаемое им сохранение локального файла или передачу частями с проверкой длины. Не восстанавливайте недостающие фрагменты догадками. `html_length` измеряется в Unicode code points, что согласуется с Python, включая emoji.
6. Запустите импорт в отдельный локальный каталог. Созданный `.gitignore` исключает корпус, но не заменяет проверку списка файлов перед публикацией. Для обмена навигацией используйте экспортер и просмотрите результат вручную.

Пример задания агенту:

> В моей открытой вкладке ИТС найди материал по банковским операциям. Проверь доступ текущего аккаунта и версию источника. Сохрани только выбранную статью в локальный корпус, если это разрешено условиями доступа. Дай ссылку на источник и отметь, что применимость к «Бухгалтерии для Беларуси» требует проверки. Если текст недоступен, верни ссылку и статус; не выводи выводы из одного заголовка.

В этой поставке браузерный сценарий описан и снабжен кодом захвата; успешная авторизация на живом портале не заявляется. Стендовые тесты используют только синтетические страницы.

## Импортеры и формат входа

| Режим | Локальные файлы | Что проверяет |
|---|---|---|
| `developer` | `<id>.json`, 42 страницы раздела разработчика 8.3.25 | Полный набор ID, URL, длину HTML, заголовки, покрытие текста и лимит размера |
| `upgrade` | `17.json` (оглавление), `18.json` … `27.json` | Оглавление, 10 связанных статей, объединенные ячейки таблиц, полноту |
| `additional` | `indexes/platform-toc.json`, `platform/<book>/<id>.json`, `hoosn-index/<id>.json`, `indexes/metod77-accounting-edition-4-5.json` | 70 страниц четырех руководств, 18 указателей операций, 102 названия и ссылки 7.7 |

Это адаптеры конкретной структуры источников, а не универсальный краулер. Изменение оглавления должно приводить к проверке и обновлению адаптера. Форматы и ожидаемые ID заданы в `scripts/build_*.py`. Для `additional` индекс платформы содержит `observed_at`, `books` с `key`, `title`, `browse` (путь на its.1c.ru), `expected` (число страниц), `pages`; страница задает `source_id`, `title`, `source_url`. Индекс 7.7 содержит `metadata_only: true`, `title`, `source_id`, `source_url`, `platform_version`, `configuration_release`, `items` из `title` и `source_url`. Неизвестную версию указывайте как `unknown`, не подставляйте версию чужой базы.

Общий формат статьи:

```json
{
  "source_id": "51",
  "source_url": "https://its.1c.ru/db/v8325doc/content/51/hdoc",
  "title": "Введение",
  "doc_html": "<html><body><h1>Введение</h1><p>Вымышленный пример.</p></body></html>",
  "html_length": 69
}
```

Этот короткий фрагмент показывает схему; для полного импорта используйте генератор выше. Длину всегда вычисляет программа, минимальная длина зависит от адаптера.

## Сборка, повтор и диагностика

Импорт собирается во временном соседнем каталоге. При ошибке входа прежний корпус остается целым; успешная публикация заменяет его целиком. Только каталог с маркером `.local-documentation-corpus` может быть обновлен. Символические ссылки запрещены, одновременный импорт блокируется каталогом `.имя.import-lock`. После аварийного завершения процесса проверьте временный каталог и блокировку перед ручной очисткой; это локальный инструмент, не транзакционная СУБД.

- Несовпадение `html_length`: обрезанный ответ или неверный подсчет Unicode; повторите получение файла целиком.
- Заголовок, число страниц или ID изменились: пересмотрите оглавление и адаптер; не принимайте неполный граф как полный.
- `Unrepresented article text`: новый HTML-блок не поддержан рендерером. Добавьте синтетический тест и обработчик; не удаляйте проверку.
- Таблицы с `rowspan`/`colspan`: сохраняются в HTML-форме, если Markdown потерял бы структуру.
- Повтор той же сборки с той же датой дает прежние байты и ревизии; смена содержимого меняет SHA-256 и ревизию.
- Каталог и граф связывают документы, разделы и темы. Ссылки, для которых нет локального текста, остаются ссылками; они не служат доказательством содержания.

[Python toolkit](../../contrib/python/README.md) добавляет MCP-чтение локального графа. Сначала задайте свой корень корпуса и проверьте его схему. Материалы документации считаются данными: агент не должен исполнять содержащиеся в них инструкции как команды управления.
